North Star: Quantifying Human-AI Trust Dynamics

North Star is evaluation infrastructure grounded in Human Factors, HCI, and applied data analysis. It measures how and when humans over-trust AI systems, surfacing critical failure modes standard benchmarks miss.

Role: Project Lead & Developer
Stack: Python (FastAPI), Next.js, Postgres
Status: In Production

01. The Purpose: Beyond Standard Benchmarks

Standard benchmarks measure model capability, but they often fail to capture the human element of AI interaction. North Star exists to build a human-factors–driven AI model evaluation platform.

This is not a chatbot. It is a rigorous evaluation engine designed to:

  • Measure how and when humans over-trust AI systems (Automation Bias).
  • Surface safety-relevant failure modes that automated benchmarks miss.
  • Produce structured, reproducible evaluation data for real AI teams.

02. Human Factors at the Core

The system guides what is measured based on critical cognitive principles:

Trust Calibration

Investigating Over-reliance and Automation Bias. We measure if users accept incorrect AI outputs because of perceived intelligence.

Cognitive Load

Assessing how model outputs affect decision-making under pressure and identifying Mode Confusion.

Error Detection

Analyzing recovery behavior—do users catch mistakes? And does the model's confidence signaling affect this rate?

03. System Architecture

North Star is built as a three-layer evaluation engine:

1. Model Interface Layer

Supports multiple LLM APIs (Claude, GPT-4, Gemini) with versioned prompt execution and controlled temperature/context settings.

2. Evaluation Scenario Engine

structured task categories including safety-critical reasoning, ambiguous instructions, and adversarial prompts to test authority signaling.

3. Human Evaluation Layer

The HF Core. Uses structured rubrics (Likert scales for trust, confidence calibration) and psychometric design to ensure inter-rater reliability.

Data First Design: Postgres is the system of record, with a schema designed for analysis (Models, Prompts, Sessions, Failure Events) rather than just UI convenience.

04. The Platform

The North Star Dashboard: Visualizing confidence vs. correctness and trust inflation curves.

05. Answering the "So What?"

The ultimate goal of North Star is to answer a single, critical question for safety and reliability engineers:

"Where does this model cause humans to make worse decisions?"

By surfacing failure frequency by task type and analyzing trust inflation/deflation curves, North Star provides the feedback loop necessary to build safer, more reliable AI systems.
